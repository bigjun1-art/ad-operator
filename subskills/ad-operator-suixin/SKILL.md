# 随心推子Skill

共用[主Skill](../../SKILL.md)的授权、按需运行和托管控制。入口是本目录 `scripts/ad.mjs`，平台固定为 `suixin`；其他工作目录运行时使用绝对脚本路径。

```sh
node scripts/ad.mjs actions
node scripts/ad.mjs describe order.terminate
```

先用 `accounts.list`读取随心推应用本次授权；它与千川PC应用分开校验，即使账户名称或ID相同，也不能互认授权。不会自动更换原应用凭据或复制凭据。

- 普通订单：`orders.list`获取完整普通订单库存，`order.get`按精确 `order_id`定位；订单库存与所选日期报表命中订单不是同一范围。
- 商品全域：`uni.orders.list`、`uni.report.get`独立查询，不与普通订单混合。当前全域订单接口不覆盖直播全域；不将不支持的类型返回空集合当成已核实没有订单。
- 概览：`overview.get`需要明确 `dim=normal`或`uni`及场景。普通趋势使用 `trend.get`。结果带 `complete=false`或范围校验失败时，只说明缺项，不产生托管动作。
- 建议与预估：`suggest.roi.get`、`suggest.bid.get`、`estimate.get`只读取。整数预算参数必须保留原接口含义；单位尚无明确依据时，不将原始值作为可提交的元金额，也不据此自动建单。
- 普通订单终止：`order.terminate`只接收本账户完整普通库存中精确匹配的 `order_id`，检查平台成功ID和回读状态。结果未知只查，不重发。

终止不是暂停，当前没有从终止状态恢复的对话动作。用户只要求“暂停”或“恢复”时，不能擅自替换成终止；先说明支持范围，需要用户决定的实际终止才补问。用户已明确要求终止具体普通订单时，沿用授权，不反复确认。

托管限定普通订单范围 `scope.dim=normal`，只允许用户明确授权的 `order.terminate`，并绑定确切订单ID、监控范围、阈值及截止时间。不能通过普通终止接口操作全域订单，也不能借千川计划预算/ROI接口操作随心推。当前未封装创建订单、修改随心推预算或ROI的动作，不用其他产品接口冒充。

托管的`cost`和`orders`取所选账户、场景的普通订单报表汇总，执行对象列表只是允许终止的订单，不会把账户成本伪装成单订单成本。用户需要按某一订单效果触发时，当前汇总规则不能直接代替；先明确支持的监控范围。

普通订单报表当前官方正文未注明金额单位。查询保留原值并附`unitKnown:false`，不能把原始消耗当作元数值触发托管。金额规则及元金额边界在单位核实前保持不可执行；仅按已核实订单数终止、且用户没有要求金额边界时，可以省略`maxObservedCost`运行明确的订单数规则。不能为了启动而擅自删除用户已给的预算或金额条件。
