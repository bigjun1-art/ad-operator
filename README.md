# ad-operator · 统一投流助手

通过对话调用现有千川、巨量本地推工作台后端，无需打开网页。普通操作按需启动临时受控进程，结束后关闭；连续监控或托管须由用户明确开启，并绑定账户、对象、动作、预算和截止时间。

这是现有工作台的Skill适配层，包含对话指令、运行控制和后端headless集成源代码；不是独立广告平台SDK，也不包含个人后端、账户或授权配置。

## 安装与配置

将本目录安装为本地 `ad-operator` Skill，使用Node.js 24以上版本。配置 `~/.config/ad-operator/config.json` 指向现有后端：

```json
{"backendRoot":"/absolute/path/to/qianchuan-console"}
```

本地配置不要放入仓库。后端需具有本仓库 `integration/` 的headless适配及对应守卫接口。完整依赖和边界见[本地配置](references/backend.md)。

```sh
node scripts/ad.mjs doctor
node scripts/ad.mjs actions qianchuan
node scripts/ad.mjs actions local
```

在对话中可以说：“用统一投流助手查询指定账户预算”“把指定计划预算调整到明确金额”“开启有明确范围和截止时间的半自动监控”。Skill先依据真实账户和当前配置确定对象，再执行用户已明确授权的操作。

## 执行方式

- `read`：查询已授权账户、报表、计划、项目、单元、素材、预算等。
- `prepare`：读取真实配置并准备具体变更，不提交。
- `execute`：只执行与当前用户授权绑定一致的账户、动作及参数。
- `managed`：显式开启持续建议或固定规则托管，可查询、停止，到期退出。[托管说明](references/managed.md)

官方ROI与计算值分别保留。元、分、千分之一分按后端已核验的接口口径处理；未知金额不补零。回执未知不自动重发，停止托管不自动暂停广告。

本地推账户日预算支持按元和两位小数操作；标准项目与全域对象分开。当前公开MAPI未提供已确认的本地推全域对象预算、目标ROI和素材生命周期专用写入，不能通过Skill绕过这个边界。历史受众查询也不作为实时账户主报表。

## 发布范围

仓库只包含技能和通用代码，没有广告账户ID、凭据、个人电脑路径、真实报表、操作回执或托管政策。本地授权与运行状态放在技能目录外。示例中的账户与对象占位符不能直接用于实际投放。

## 测试

```sh
node --test scripts/*.test.mjs
```

测试只使用注入驱动和隔离临时目录，不向真实广告账户提交变更。集成源代码的HTTP与生命周期测试需在现有后端项目中运行。
